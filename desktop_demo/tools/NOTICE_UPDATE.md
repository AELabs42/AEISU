# AEISU private preview: notice correction

Extract this notice ZIP directly into the existing AEISU demo folder. Keep the
`licenses/` directory beside `AEISU Demo.exe`; allow the runtime index to be updated.
The original upstream license texts are retained unchanged. The added CUTLASS
and cuDNN Frontend notices, including its JSON dependency, cover header code compiled into the native backend.

This ZIP contains only license texts, the runtime index and these instructions.
It contains no executable, model, DLL, SDK, dataset, or installation program.
It does not modify model behavior, UI, performance, or the original release checksums.
The original package manifest describes the original package, not this separate overlay.

This correction is prepared locally for the private 0.1.2 preview, which upgrades
the complete 0.1.0 runtime package. It is not a standalone application and does
not establish clearance for public binary distribution. See THIRD_PARTY_RUNTIME.md.
